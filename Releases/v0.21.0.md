# Квиз Студия 0.21.0

Выпуск добавляет обновление приложения из приложения: новые версии можно получать без повторного скачивания ZIP с GitHub.

## Обновления

- «Квиз Студия» проверяет обновления через Sparkle автоматически при запуске, не чаще примерно раза в сутки. Проверка идёт в фоне и не задерживает запуск, игру или редактор.
- В меню «Квиз Студия» появилась команда «Проверить обновления…». Она сразу показывает стандартный результат: доступная версия и заметки релиза, «Обновлений нет» или сообщение об ошибке.
- Обновление никогда не устанавливается и не перезапускает приложение без согласия: доступны варианты установить сейчас или отложить.
- Неподходящие по версии macOS и архитектуре пакеты не предлагаются; принимаются только пакеты с валидной подписью EdDSA, а подпись приложения проверяется и не может быть удалена. Повреждённая или подделанная загрузка отклоняется.
- При отсутствии сети или ошибке ленты приложение продолжает работать и не показывает навязчивых диалогов.
- Проверка отправляет только стандартный запрос Sparkle за лентой; телеметрия, профилирование и передача данных о квизах не включены.

## Первое обновление вручную

Версии 0.20.0 и более ранние не содержат обновлятора, поэтому один раз приложение нужно заменить вручную:

1. Скачайте ZIP со страницы [последнего релиза](https://github.com/totchto/quiz-studio-macos/releases/latest).
2. Распакуйте и перенесите «Квиз Студия.app» в «Программы», заменив старую копию.
3. Запустите приложение; дальнейшие обновления будут приходить через «Проверить обновления…».

Квизы `.quiz`, банк вопросов, архив игр и настройки при замене приложения не затрагиваются.

## Сборка

- Sparkle 2.10.1 встроен в приложение; `build.py` подписывает вложенные компоненты, добавляет необходимый rpath и по требованию заверяет сборку нотариусом.
- Сборка 0.21.0 подписана ad hoc, без нотариального заверения Apple. Обновления при этом работают: архив подписан EdDSA, и Sparkle принимает ad-hoc сборки. Developer ID рекомендован для нотаризации и стабильной identity, но не является обязательным для обновлений.
- При первой ручной установке Gatekeeper может попросить открыть приложение через контекстное меню. Дальнейшие обновления приходят из приложения.
- Лента обновлений и ZIP публикуются в GitHub Releases; адрес ленты постоянный — `https://github.com/totchto/quiz-studio-macos/releases/latest/download/appcast.xml`.
- Подготовка ключей и выпуск описаны в `docs/superpowers/notes/sparkle-keys.md`.

## Проверки

- `python3 Tests/check_updates.py` — настройки ленты, открытый ключ, политика проверок и версия Sparkle.
- `codesign --verify --deep --strict "dist/Квиз Студия.app"` — подпись приложения и вложенного Sparkle.
