# Quiz Studio: текущий контекст

Нативное приложение для проведения квизов: SwiftUI/AppKit/AVFoundation, Apple Silicon, macOS 14+. Swift tools 6.0, language mode 5. Команды отвечают на бланках либо через браузер телефона в локальной сети; показ игры — на ТВ.

## Версия и расположение
- Репозиторий: `totchto/quiz-studio-macos`, основная ветка `main`.
- Последний подтверждённый опубликованный релиз: `v0.17.0` — массовый импорт, подборка из банка, новые типы вопросов, правила баллов, блоки раунда, маски изображений и подробные отчёты.
- Полные изменения релиза `v0.17.0` относительно `v0.16.0`: `Releases/v0.17.0.md`.
- Корень разработки — каталог этого файла; артефакты сборки — `dist/`.
- Эти сведения — отправная точка. Перед новой публикацией проверь актуальные Git/Release; для обычной правки сетевой запрос не нужен.

## Данные и ограничения
- `.quiz` — переносимый JSON-контейнер `QuizFile` со встроенными медиа; сохраняется чтение старых квизов. Монтаж недеструктивный, оригинал сохраняется.
- Локальные данные: `~/Library/Application Support/QuizStudio/`; банк — `QuestionBank/`, архив — `GameArchive/`, шаблоны — `RoundTemplates.json`.
- Для тестов `Studio(draftURL: ...)` использует временное рабочее место. Не тестируй на настоящем черновике/банке пользователя.
- Предпросмотр не должен менять квиз, баллы, историю, архив, восстановление, комнату телефонов или ТВ.
- SIQ 3–5 преобразуется в последовательный квиз; ставки, поле клеток и скрипты SIGame не воспроизводятся.
- За полное правильное сопоставление в игре с телефонов — 1 балл; частичное — 0. Свободные ответы допускают ручную проверку.
- В статистике разделены верные, неверные, непроверенные и отсутствующие ответы; непоказанные вопросы исключены. Для бланков есть результаты по раундам, без отдельных ответов.
- В релизе встроены yt-dlp/Deno; версии и хеши — `ImportTools.lock.json`, уведомления — `Resources/YOUTUBE-CREDITS.txt`. Для загрузки с YouTube нужен интернет.
- Подпись ad hoc, без нотариального заверения Apple; сборки для Intel нет.

## Проверки: запускать по затронутой области
| Область изменения | Команда из корня репозитория |
| --- | --- |
| Массовый импорт, подборка и новые типы, HTTP | `python3 Tests/check_new_features.py` |
| Формы телефона и отправляемые данные | `node Tests/check_phone_forms.js` |
| Общая логика, модели, сохранение, порядок игры | `python3 Tests/run.py` |
| Медиа и проигрывание | `python3 Tests/check_media.py` |
| Телефоны, HTTP, оценки, восстановление комнаты | `python3 Tests/check_phones.py` |
| YouTube без сетевой загрузки | `python3 Tests/check_youtube.py` |
| SIQ, синтетические паки | `python3 Tests/check_siq.py` |
| Банк | `python3 Tests/check_bank.py` |
| Шаблоны, массовые настройки, предпросмотр, история | `python3 Tests/check_editor.py` |
| Архив и статистика | `python3 Tests/check_archive.py` |

Некоторые проверки собирают временный Swift-harness из исходников и могут быть длительными. При их ошибке смотри конкретную диагностику. Тесты SIQ/банка с необязательным реальным паком ожидают определённый регрессионный пак — произвольный пользовательский SIQ для этого не подходит.

## Сборка и выпуск
- Компиляция: `swift build -c release`.
- Полная упаковка: `python3 build.py` → `dist/Квиз Студия.app`, `dist/QuizStudio-macOS.zip`.
- Если отсутствуют импорт-компоненты: сначала `python3 prepare_import_tools.py` (сеть). Имеющиеся компоненты без причины не скачивай заново.
- Проверка подписи: `codesign --verify --deep --strict 'dist/Квиз Студия.app'`.
- В последней публикации GitHub-коннектор читал репозиторий, но запись отклонялась с 403. Push успешно выполнен встроенным Git в VS Code; релиз и ZIP опубликованы через авторизованный Safari. CLI `gh` тогда отсутствовал. Это прошлое наблюдение, не гарантия текущего доступа.
- Не выводи токены/credentials. Не извлекай авторизацию из браузера; используй поддерживаемый вход и инструменты.
