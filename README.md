# Квиз Студия для macOS

Редактор и автоматическое проведение квизов на Mac и телевизоре. Версия **0.5.0**. Mac с Apple Silicon, macOS 14 и новее.

## Скачать

- [Готовое приложение](QuizStudio-0.5.0-macOS-arm64.zip) — распакуйте ZIP и откройте «Квиз Студия.app».
- [Полный проект с исходниками](QuizStudio-source-0.5.0.zip) — исходники Swift, тесты, инструкция, ресурсы, пример квиза и скрипт сборки. Распакуйте для разработки.
- [Пример игры](Demo.quiz) — один файл, который можно открыть в приложении.

## Возможности

Редактор раундов и вопросов, выбор одного из четырёх ответов, открытые вопросы и сопоставление с перемешиванием. Картинки, локальное аудио и видео с выбором фрагмента, таймеры, запикивание интервалов, объяснения вопросов и раундов. Автоматическое проведение, повтор вопросов, раскрытие ответов, представление команд и промежуточные итоги. Отдельный экран ТВ, управление стрелками и пробелом. Квизы сохраняются одним переносимым файлом `.quiz` со всеми медиа; старые папки также открываются.

## Сборка из исходников

Распакуйте архив проекта, откройте `QuizStudio/Package.swift` в Xcode или запустите из папки `QuizStudio`:

```sh
python3 build.py
```

Приложение и ZIP появятся в `dist/`. Для проверки логики выполните `python3 Tests/run.py`.

## Состояние версии

Это рабочий прототип. Сборка и автоматические проверки логики и формата файлов прошли. Полная визуальная проверка, работа с реальным ТВ и реальными медиа ещё требуют проверки. YouTube, графическая звуковая дорожка, нормализация громкости и восстановление позиции игры пока не реализованы. Приложение подписано локально (ad hoc), без нотариального заверения Apple.

Подробная инструкция и ограничения находятся в README внутри архива исходников.
